# Sophisticated Auto Walk

[![CurseForge Downloads](https://cf.way2muchnoise.eu/full_1222942_downloads.svg)][curseforge] [![Minecraft Versions](https://cf.way2muchnoise.eu/versions/1222942.svg)][curseforge] [![Download on CurseForge](https://img.shields.io/badge/Download-CurseForge-F16436?logo=curseforge&logoColor=white)][curseforge]

Sophisticated Auto Walk is a lightweight, client-side minecraft mod that lets you toggle automatic forward movement with a keybind (default: middle mouse button).

Including several configurable options to enhance control and auto walking:

- Keep sprinting active (normally gets disabled on block collision)
- Stops when interacting with blocks (e.g., opening chests, mining noninstant blocks)
- Stops when interacting with entities (e.g., talking to villagers, attacking mobs)
- Stops when using an item (e.g., eating, shooting a bow)
- Stops after inactivity (customizable timeout)
- Stops when entering/leaving water (default:false)
- Stops when opening an UI (default:false)

## Installation

1. Install the required mod loader.
2. Download the mod from the official CurseForge page.
3. Place the `.jar` file in your `mods` folder.
